# 测试数据创建指南

## 原则

1. **使用 PowerShell 脚本通过 HTTP API 创建**（先在 `localhost:9300` 登录）
2. **每个入站必须有 2 个以上客户端**（除了 tunnel/tun 等无客户端协议），以测试多客户端功能和订阅客户端级引用
3. **`total` 始终设为 0**（不限流），避免后端 `disableInvalidInbounds` 自动禁用入站
4. **订阅的 `inboundIds` 必须包含 `:clientId`**（如 `"1:3"`），否则 `clientCount` 显示为 0
5. **更新文档后记得清理脚本文件**

## PowerShell 注意事项

### 字符串拼接

用 `+` 操作符拼接字符串，不要在单引号字符串内插变量：

```powershell
# ✅ 正确（用 + 拼接）
$s='{"email":"'+"${prefix}_${i}_${rnd}"+'@t.com","id":"'+"${uuid}"+'"}'

# ❌ 错误（单引号内的 $ 不会被求值）
$s='{"email":"${prefix}_${i}_${rnd}@t.com"}

# ❌ 错误（双引号嵌套变量导致解析失败）
$s='{"email":"vmess_'"$rnd"'@t.com"}'
```

### `Get-Random` 参数写法

```powershell
# ✅ 正确（参数名和值之间有空格）
Get-Random -Minimum 1000 -Maximum 9999
Get-Random -Minimum 1 -Maximum 100

# ❌ 错误（无空格被解析为命令名）
Get-Random-Minimum 1000-Maximum 9999
```

### `: ` 在 PowerShell 字符串中的问题

`$variable:` 会被解析为 PSDrive 引用。避免在字符串中让变量名后紧跟冒号：

```powershell
# ❌ 错误
Write-Host "  [FAIL] $p-$i: $text"

# ✅ 正确
Write-Host "  [FAIL] $p-$i"
# 或
Write-Host "  [FAIL] $($p)-$($i)"
```

### JSON 转义

```powershell
# settings JSON → 嵌入外层 JSON 的字符串字段
$settings='{"clients":[{"email":"a@t.com","enable":true}]}'
$escaped = $settings -replace '"','\"'
$payload='{"settings":"' + $escaped + '","enable":true}'
```

## 入站 Settings 格式（按协议）

每种协议的 settings JSON 字段必须正确，否则 `AddInbound` 会报错：

| 协议 | Settings 格式 | 关键字段 |
|------|-------------|---------|
| vmess | `{"clients":[{"email":"...","id":"uuid","enable":true}]}` | `id`（UUID） |
| vless | 同上 | `id`（UUID） |
| trojan | `{"clients":[{"email":"...","password":"...","enable":true}]}` | `password`（非 UUID） |
| shadowsocks | `{"method":"chacha20-ietf-poly1305","clients":[{"email":"...","password":"...","enable":true}]}` | `method` + `password` |
| wireguard | `{"peers":[{"publicKey":"...","endpoint":"...","allowedIPs":[...]}],"secretKey":"..."}` | `peers` 数组 |
| hysteria | `{"clients":[{"email":"...","auth":"...","enable":true}]}` | `auth`（非 UUID） |
| mixed | `{"auth":"password","accounts":[{"user":"...","pass":"..."}]}` | `accounts` 数组 |
| http | 同上 | 同上 |
| tunnel | `{"rewriteAddress":"...","rewritePort":443,...}` | 无 clients 数组 |
| tun | `{"name":"...","mtu":1500,...}` | 无 clients 数组 |

## UUID 格式

必须满足 `8-4-4-4-12` 共 36 字符的 UUID 标准格式：

```powershell
# ✅ 有效
$uuid="aaaaaaaa-aaaa-aaaa-aaaa-aaaaaaaaa001"

# ❌ 无效（最后一段超过 12 位）
$uuid="aaaaaaaa-aaaa-aaaa-aaaa-10000000000aa1"  # 14 位，应为 12 位
```

## 完整部署流程

```powershell
# 1. 删除旧容器
docker rm -f 3xui-test

# 2. 构建新镜像
docker build --no-cache -t 3x-ui-test .

# 3. 启动容器（开放面板 + 订阅端口）
docker run -d --name 3xui-test -p 9300:2053 -p 2096:2096 3x-ui-test

# 4. 运行测试数据脚本
powershell -ExecutionPolicy Bypass -File .\seed.ps1

# 5. 验证订阅链接
curl http://localhost:2096/sub/ts_0000000001

# 6. 清理脚本文件
Remove-Item .\seed.ps1
```

## 验证要点

| 检查项 | 命令 |
|--------|------|
| 所有入站 enable=true | `GET /panel/api/inbounds/list` → 检查 `enable` 字段 |
| 订阅链接可用 | `curl http://localhost:2096/sub/ts_0000000001` → HTTP 200 |
| 页面正常加载 | 所有页面长度 > 1426 bytes |
| Windows 换行符 | 复制到 Docker 的 shell 脚本必须先转 LF |
